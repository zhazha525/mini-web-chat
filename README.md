# 小型网页聊天（零依赖，电脑 / 手机浏览器通用）

一个极简实时聊天网页：同一份响应式页面，电脑和手机浏览器都能直接打开用。
技术：Node 内置 `http` + SSE（服务器推送），**不需要安装任何 npm 包**，丢到能跑 Node 的地方就能用。

## 文件
- `server.js`：聊天服务（同时托管前端页面 + 实时接口）
- `public/index.html`：聊天页面（自适应手机/电脑）
- `package.json`：启动脚本

## 本地跑
```bash
cd 网页聊天版
node server.js
# 浏览器打开 http://localhost:3000
```
手机和电脑连同一网络，直接用服务器局域网 IP 访问即可联调。

## 给"家里的人"用（两种部署）

### A. 复用家里小主机 + Tailscale（推荐，最私有）
1. 小主机装 Debian + Node 18+，把本目录放上去，`node server.js`。
2. 小主机装 Tailscale：`curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up`。
3. 同事手机/电脑装 Tailscale，登录同一账号。
4. 访问 `http://<服务器tailscale内网IP>:3000` —— 不开任何公网端口。

### B. 直接放到公网（不用装 Tailscale，但需加房间钥匙）
- 部署到任意支持 Node 的平台（Render / Railway / 你的 VPS / Cloudflare Workers 需改写）。
- 设置环境变量 `ROOM_KEY=一段随机串`，访问必须带 `?key=那段串`，否则 403。
- 分享链接形如：`https://你的域名/?room=team&key=那段串`，同事打开即聊，外人进不来。

## 多人分房间
URL 带 `?room=xxx` 即进入不同房间，例如：
- 你和小红：`?room=xiaohong`
- 项目群：`?room=project`

## 像微信群一样拉人（邀请链接）
- 打开 `http://<服务器地址>:3000/home`，输入群名 → 自动生成专属邀请链接。
- 把链接发到微信/任意地方（**只发链接**，敏感内容到群里再聊，别在微信里说）。
- 对方点开链接、填昵称即进群，多人实时同聊，无人数上限、无平台审核。
- 聊天页右上角有「邀请」按钮，一键复制当前群链接。
- 想要完整「频道 + 账号 + 手机 App + 管理后台」体验（更接近企业微信），直接用上层目录的 Rocket.Chat / Matrix Synapse 方案，同样自建、同样私有。

> 注：自建群只解决平台误判与隐私问题，群内发言的合规性仍由你们自行把握。

## 当前能力边界（小型版，按需再加）
- 消息存内存（重启清空）。要持久化可接入 SQLite/文件，或前端已带首屏最近 50 条。
- 无账号体系，靠昵称 + 可选房间钥匙区分。要更强权限可换前面的 Rocket.Chat / Synapse 方案。
- 实时靠 SSE，手机锁屏后浏览器可能暂停连接，回到前台会自动重连并补历史。
